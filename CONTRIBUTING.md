# Contributing

Thank you for your interest in contributing to this project!

Important:

- This project, like the rest of the projects listed under the maintainer's [Web Project Index](https://github.com/kevinbowen777/web-project-index/blob/master/README.md), are primarily developed for personal educational purposes. Use at your own risk.
- Use of LLMs and other generative AI tools is not allowed.
- Don't be a jerk.

## Issues

If you have found a bug in this project, consider the following guidelines.

Please do:

- Check [existing issues](https://github.com/kevinbowen777/learning-log/issues) to verify that the bug or feature request has not already been submitted.
- Open an issue if things aren't working as expected.
- Open an issue to propose and discuss a significant change.
- Open an issue to discuss the proposal of any new features.

Please avoid:

- Commenting on an issue and requesting it be assigned to you. If the maintainer has never had any prior interaction with you, these requests will be automatically declined.

## Pull requests

This project does not accept unsolicited pull requests.

If you are interested in contributing to this project, please introduce the change you wish to make to the maintainer by opening an issue, introducing yourself, and providing details on the changes. Perhaps we can collaborate together improving the project.

Once the maintainer accepts your proposed change and allows you to work on it, you will receive instructions on how to submit a pull request.

## Reporting a vulnerability

If you believe that you have found a security vulnerability in this repository,
outside of its upstream package dependency issues, do not open a public issue.
Please contact the maintainer(see below) with details.

## Contacting the maintainer

You can contact the maintainer (Kevin Bowen) by [email](mailto:kevin.bowen@gmail.com), social media, or by writing a draft issue in this project.
